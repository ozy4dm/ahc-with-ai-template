# Claude Code に渡すプロンプト例

このテンプレートは長期 AHC の **With AI 部門** 向けです。大会の「部門」タブで With AI を選択し、開催時点の公式ルールを確認してから使用してください。Claude Code はリポジトリのルートで起動し、`/context` で `CLAUDE.md` と `AGENTS.md` の読み込みを確認します。

以下の `［...］` は大会ごとに記入します。AI に解法や実験方針の考案を依頼して構いません。参加者が指定した条件と AI の提案は、記録で区別します。

## 大会の準備

```text
/ahc-setup 対象大会: ［大会名］。With AI 部門を選択済みです。適用ルール: ［公式URL］。問題文: ［手動で保存した local/ 内の場所］。使用言語: ［言語］。公式ツール: ［手動で保存した tools/ 内の場所］。採点方法と制限時間を確認し、作業環境を整えてください。AtCoder へのログインや取得は行わないでください。
```

## 解法の検討と実装

```text
/ahc-implement 問題文と公式ツールを確認し、解法候補を考案して比較してください。有望な案を選び、新しい版として実装・テストしてください。考案した方針、選択理由、計測結果を記録してください。既存版と結果は上書きしないでください。
```

## 指定した解法の実装

```text
/ahc-implement 対象の版: ［ID］。実装するアルゴリズムと処理順序: ［仕様］。評価関数・パラメータ・停止条件: ［仕様］。この指定を優先して実装し、仕様との一致を確認してください。実装上の裁量が必要な点は明示してください。
```

## 不具合修正

```text
/ahc-implement 対象の版: ［ID］。期待する動作: ［仕様］。実際の動作と再現ケース: ［事実・ケースID］。今回は解法を変更せず、不具合の原因を調査・修正してください。変更後に再現ケースと関連テストで確認してください。
```

## 比較実験と改善

```text
/ahc-experiment 比較したい版: ［版IDまたは目的］。ケース集合: ［集合またはAIに設計を依頼］。時間制限と採点方法を確認し、比較条件を先に記録してください。実験を実行して結果を分析し、改善案と次の検証方法を提案してください。追加実験は別のIDで記録してください。
```

スキルを使わない通常のメッセージでも、同じ内容を依頼できます。
