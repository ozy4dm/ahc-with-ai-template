# 実験の記録

1. `docs/experiments/TEMPLATE.md` を複製し、比較対象、ケース集合、時間制限、スコアの向き、評価基準を実行前に記入する。AI が決めた条件はそのように記す。
2. ケース集合を固定して比較を実行し、結果の CSV と JSON を保存する。
3. 結果を集計・分析し、観測事実と解釈を分けて実験記録へ追記する。
4. 改善案や次の実験を考案してよい。条件や解法を変えたときは新しい版・実験 ID を使い、既存の結果を上書きしない。
5. 採用・棄却と理由、提案者、判断者を `docs/decisions.md` に記録する。

このワークフローは長期 AHC の With AI 部門向けです。開催時点の公式ルールと大会固有の条件を確認してください。
